InfiniClick — Simulator

Runs the real ball/brick physics on each layout (layout.js, a normalised square field) to measure one number per layout: the effective damaging-hit rate per ball on a full high-HP board. Hits scale linearly with ball count, so one number is enough. From it we derive each layout's suggested HP % (hit-rate ÷ the grid's) — put it in config.js's LAYOUT_HP_PERCENT so every layout clears in a similar time. Feeds stats.html.
